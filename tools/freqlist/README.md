# English word frequency list

`en_50k.txt` is the 50,000 most frequent English words, with occurrence
counts, from movie and TV subtitles - everyday language, which is exactly
what a kids' word game wants.

Format: `{word} {count}`, most frequent first, lowercase.

## Source and license

Taken from [FrequencyWords](https://github.com/hermitdave/FrequencyWords)
by Hermit Dave (`content/2018/en/en_50k.txt`), generated from the
[OpenSubtitles2018](http://opus.nlpl.eu/OpenSubtitles2018.php) corpus.

The list is licensed **CC-BY-SA-4.0** (unlike the rest of this repository,
which is 0BSD). Lists for 60+ other languages are available at the same
place, in the same format.
